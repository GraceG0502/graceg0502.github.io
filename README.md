# 个人网页项目

使用 React + Vite 构建的个人网页

## 项目结构

```
personal_web/
├── public/              # 静态资源目录
├── src/                 # 源代码目录
│   ├── assets/         # 图片、字体等资源文件
│   ├── components/     # 可复用组件
│   ├── pages/          # 页面组件
│   ├── utils/          # 工具函数
│   ├── App.jsx         # 主应用组件
│   ├── main.jsx        # 应用入口
│   └── index.css       # 全局样式
├── index.html          # HTML 模板
├── package.json        # 项目配置
└── vite.config.js      # Vite 配置
```

## 开发命令

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```
